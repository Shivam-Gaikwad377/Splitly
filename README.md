# Splitly

Splitly is a full-stack expense-sharing application inspired by Splitwise.

## Project Structure

- `backend/` — Express, TypeScript, and PostgreSQL API.
- `frontend/` — React, Vite, TypeScript, and shadcn/ui application.
- `docs/` — Project logs and supporting documentation.
- `SRS.md` — Software requirements specification.
- `Tech_specifications.md` — Technical specifications.
- `Auth api contract.md` — Authentication API contract.

## Development

Backend setup and commands are documented in `backend/README.md`
and `backend/package.json`.

Frontend setup instructions will be added when the frontend is initialized.

## Status

Backend authentication has been implemented and tested.
Frontend development is beginning.
